# Demo Dating Telegram Bot

Быстрый пробный бот знакомств для показа идеи. Внутри две фейковые анкеты с AI-сгенерированными картинками, кнопки лайка, пропуска, следующей анкеты и простая статистика.

## Запуск

1. Создай бота через [BotFather](https://t.me/BotFather) и получи токен.
2. Скопируй `.env.example` в `.env`.
3. Вставь токен:

```env
BOT_TOKEN=123456:telegram_token_here
```

4. Установи зависимости и запусти:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python bot.py
```

5. Открой своего бота в Telegram и отправь `/start`.

## Что можно показать

- Листание анкет.
- Лайк и пропуск.
- Статистику действий.
- Как легко заменить демо-анкеты в `data/profiles.json`.

Это прототип без базы данных и реальных пользователей. Для прода дальше нужны регистрация, модерация, хранение профилей, гео/фильтры и антиспам.
